## 二、本次新增的 4 个功能

### 1. 开机自启（新增开关）

界面新增「启动与快捷键」卡片，第一行是**开机自启**开关。

- 打开后写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `HotkeyGuard` 值，
  指向程序自身路径，并附加 `--autostart` 标记
- 关闭后删除该值
- 程序每次启动会回读注册表做一次对齐：**程序被移动过位置时会自动修正路径**；
  旧版本写下的无标记值也会自动迁移成带标记的格式
- 关闭自启时不会误删别人写入的同名注册表值

### 2. 开机自启时，默认进入「正常模式」

**这是对原程序行为的一处修正。** 原程序启动时会恢复上次保存的模式，所以如果你上次退出时是
「游戏模式」，开机自启后它也会直接进游戏模式，一路拦截快捷键。

现在只要是通过自启启动（带 `--autostart`），运行时模式**强制为「正常模式」**。

> 注意：这只改**这一次运行时的模式**，**不会改写你保存的偏好**。
> 你手动双击启动时，仍然恢复成你上次保存的模式（比如游戏模式）。
> 自启那一次是正常模式，手动打开还是游戏模式 —— 两者互不干扰。

### 3. 「自启时最小化到托盘」开关（新增）

卡片第二行。打开后，**自启启动时窗口完全不显示**，程序直接驻留系统托盘后台运行。

- 窗口是「自始至终不显示」，不是「先显示再收起」，不会有闪一下的观感
- 需要调设置时，**左键单击托盘图标**即可唤回窗口（菜单第一项「显示 / 隐藏窗口」）
- 该开关**只对自启启动生效**。手动双击启动时，窗口照常显示

### 4. 自定义切换快捷键（含 Ctrl / Alt / Shift 修饰键）

原程序的模式切换键是**硬编码的 F8**，无法更改。现在：

- 卡片第三行是**切换快捷键**按钮，点一下进入录制状态，**直接按你想用的组合键**即可
  （例如按 `Ctrl+F9`，它会把 Ctrl 和 F9 一起记下来）
- 左侧有 `Ctrl` / `Alt` / `Shift` 三个勾选框，可以单独微调修饰键，不必重新录制
- 录制时按 `Esc` 取消
- 设置随 `settings.json` 一起保存，重启不丢
- 底部提示文字会同步显示当前组合，例如 `Ctrl+F9 切换模式`

**默认值**：未配置过时是 `F8`（与原程序一致），装了之后想改就改。

## 三、使用速览

1. 双击 `HotkeyGuard_增强版.exe` 启动
2. 顶部切到**游戏模式**，勾选要禁用的快捷键（默认已勾选常用项）
3. 进游戏开打；按你设定的切换键（默认 `F8`）可随时切回正常模式
4. 在「启动与快捷键」卡片里按需打开：**开机自启** / **自启时最小化到托盘**，并设定**切换快捷键**
5. 点关闭按钮 = 最小化到托盘，程序继续后台拦截；右键托盘图标可切换模式 / 退出

## 四、改动边界（可审计）

本版本对原程序的改动范围是**可精确界定的**：

| 项 | 状态 |
|---|---|
| PyInstaller bootloader（前 307,712 字节） | 逐字节一致 |

**界面尺寸保持不变**（窗口仍为 500×720 不可缩放），新增的卡片行利用了原有布局的富余空间。

## 六、已知事项

1. **本仓库 `源码/` 目录里是 v1 源码，与 v2 不对应。**
   v2（含本增强版）的原始源码从未提交到本仓库，因此**无法用 `源码/` 目录直接构建出本版本**。
   本版本的改动集中在入口层，如需审计可联系作者。
2. 增强版是**独立文件**，不影响仓库里既有的 `HotkeyGuard.exe`（v1），两者可共存。
3. 拦截基于 Windows 标准低级键盘钩子（`WH_KEYBOARD_LL`），不注入 DLL，
   不触碰游戏内存，不会触发 VAC / 反作弊。
4. `Ctrl+Alt+Del` 是系统安全键，任何软件都无法拦截。
5. 若杀毒软件报毒：这类「全局拦截键盘」的程序被误报属常见现象，
   本程序不含任何网络行为，可自行加白名单。

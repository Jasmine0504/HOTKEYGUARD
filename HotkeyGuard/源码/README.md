# HotkeyGuard · 快捷键守卫

打 CS2 时防误触的快捷键拦截器。游戏模式下手动选择要禁用的快捷键，正常模式下完全放行。

## 使用

1. 双击 `HotkeyGuard.exe` 启动
2. 顶部切换 **游戏模式** → 勾选要禁用的快捷键（默认已勾选常用项）
3. 进游戏开打；按 **F8** 可在游戏中随时切回正常模式（有提示音，无需切出游戏）
4. **点关闭按钮 = 最小化到托盘**，程序继续后台拦截；右键托盘图标可切模式/退出
5. 退出 = 托盘菜单点「退出」，所有拦截立即解除

## 可禁用的快捷键

| 快捷键 | 说明 | 默认 |
|---|---|---|
| Windows 键 | 全部 Win 组合（Win+D/Tab/E/L/Space…） | 开 |
| Alt + Tab | 切换窗口 | 开 |
| Ctrl + Space | 中英文输入法切换 | 开 |
| PrintScreen | 截图（含 Alt+PrtSc） | 开 |
| Alt + Esc / Alt + F4 / Ctrl + Esc / Ctrl + Shift | 按需开启 | 关 |

## 说明

- **F8** 是全局切换热键，任何模式下都生效（按一下切换模式，两声不同提示音）
- 关闭窗口会驻留系统托盘（右下角），后台继续拦截；托盘菜单可切换模式、退出
  - 若托盘没看到图标，点托盘区的 `^` 展开箭头找到它，可拖到常驻区
- 设置自动保存到 `%APPDATA%\HotkeyGuard\settings.json`，重启不丢
- 正常模式下点 **恢复默认设置** 可重置勾选
- 拦截范围是全局的：游戏模式开着时，所有程序里这些组合键都会被吞掉
- Ctrl+Alt+Del 是系统安全键，任何软件都无法拦截
- 若用搜狗等第三方输入法仍有组合键切输入法，建议同时在输入法设置里关闭其快捷键
- 使用 Windows 标准低级键盘钩子（WH_KEYBOARD_LL），不注入 DLL，不会触发 VAC/反作弊
- 退出程序或切换回正常模式后，所有按键立即恢复

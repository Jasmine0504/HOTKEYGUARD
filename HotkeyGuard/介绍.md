## 详细版介绍

### 是什么

HotkeyGuard（快捷键守卫）是一个 Windows 桌面小工具，用于在游戏时屏蔽容易误触的系统快捷键。专为 CS2 等竞技游戏设计——关键时刻一个误触切出游戏，可能就是一场对局的失利。

### 核心功能

**游戏模式**
- 8 个常用误触快捷键可自由勾选禁用：Windows 键（含全部 Win 组合）、Alt+Tab、Alt+Esc、Alt+F4、Ctrl+Esc、Ctrl+Space（中英文切换）、Ctrl+Shift（输入法循环）、PrintScreen
- 默认勾选最常误触的 4 项（Win 键、Alt+Tab、Ctrl+Space、截图键），也可完全自定义

**正常模式**
- 一键关闭所有拦截，系统行为恢复原样
- 内置「恢复默认设置」，一键还原推荐配置

**体验细节**
- F8 全局切换热键：游戏中盲按即可在两种模式间切换，带高低音提示，无需切出游戏
- 设置自动保存：勾选状态和模式都会记住，下次打开直接可用
- 关闭窗口时可选择：后台驻留系统托盘继续拦截 / 彻底退出 / 取消
- 托盘右键菜单可直接切换模式或退出

### 技术特点

- 使用 Windows 低级键盘钩子（WH_KEYBOARD_LL），在按键到达系统前拦截，响应即时、零延迟影响
- 不注入任何 DLL、不修改系统文件、不联网、无广告
- 正常途径的输入拦截，不会触发 VAC / 反作弊检测（与主流按键工具同类机制）
- 内存占用极小（约 30MB），对游戏性能无影响
- 绿色便携单文件，无需安装，64 位 Windows 双击即用

### 适用场景

- CS2 / VALORANT / 各类 FPS 竞技游戏防误触
- 需要长按 Win 键、Alt 键操作的游戏（如部分策略游戏）
- 直播/录屏时防止误触切出窗口
- 一切「手滑党」的救星

### 小提示

- Ctrl+Alt+Del 是系统安全键，任何软件都无法拦截
- 若使用搜狗等第三方输入法，个别输入法自带快捷键建议同时在输入法设置中关闭
- 首次运行如遇 Windows SmartScreen 提示（未签名软件的正常现象），点「更多信息 → 仍要运行」即可
